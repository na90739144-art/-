# کافی‌نت هوشمند: بستهٔ کامل (وب + APK + گیت‌هاب + مایکت و بازار)

## ساختار
```
web/                  سایت کامل (index.html, styles.css, app.js, config.js, sw.js, manifest, privacy.html)
android/              پروژهٔ اندروید (WebView) که پوشهٔ web را داخل APK می‌گذارد
functions/worker.js   نمونهٔ Worker کلودفلر (فعلاً وصل نیست)
wrangler.toml         تنظیمات Worker
.github/workflows/    pages.yml (انتشار سایت)، android.yml (ساخت APK)
store/                آیکن ۵۱۲ و ۱۰۲۴ و متن آمادهٔ معرفی برای مایکت/بازار
SECURITY.md           نکات امنیتی
```

## ⚠️ قبل از انتشار در مایکت و بازار (حتماً بخوانید)
1. **حساب کاربری فعلاً فقط روی همان گوشی ذخیره می‌شود** (ایمیل جیمیل و رمز؛ رمز به‌صورت هش‌شده). یعنی در گوشی دیگر نمی‌شود با همان حساب وارد شد و رمز فراموش‌شده بازیابی نمی‌شود. ورود واقعی چنددستگاهی به سرور نیاز دارد. این را در معرفی برنامه ادعا نکنید.
2. پاسخ‌ها فعلاً **آماده و ثابت** هستند، نه زنده از هوش مصنوعی. در توضیح برنامه ادعای هوش مصنوعی زنده نکنید.
3. نشانی سایت‌های رسمی از حافظه نوشته شده و **زنده بررسی نشده**. پیش از انتشار تک‌تک را باز و تأیید کنید (فایل `web/app.js`، فهرست‌ها).
4. شرایط، هزینه و مهلت هر خدمت «تأیید نشده» است. تا از منبع رسمی ثبت نکنید، چیزی ادعا نکنید.
5. برنامه نباید شبیه برنامهٔ رسمی دولتی یا بانکی باشد؛ از آرم و نام سازمان‌ها در آیکن و تصاویر استفاده نکنید. جملهٔ «رسمی نیست» حذف نشود.
6. **میکروفون و مکالمهٔ صوتی** در APK با تشخیص گفتار خود اندروید کار می‌کند (اجازهٔ میکروفون از کاربر پرسیده می‌شود). تشخیص گفتار فارسی معمولاً به اینترنت و سرویس گوگل روی گوشی نیاز دارد و روی بعضی گوشی‌ها (مثلاً بدون خدمات گوگل) ممکن است در دسترس نباشد. خواندن پاسخ با صدا هم به صدای فارسی نصب‌شده بستگی دارد. روی گوشی واقعی حتماً امتحان کنید.
7. فونت وزیرمتن از Google Fonts می‌آید. بدون اینترنت یا با فیلتر، فونت سیستم نشان داده می‌شود. برای نسخهٔ پایدارتر فایل فونت را دانلود و داخل `web/fonts/` بگذارید و با `@font-face` در `styles.css` معرفی کنید.

## ۱) انتشار سایت روی GitHub Pages
1. یک مخزن بسازید و کل محتوای این پوشه را در شاخهٔ `main` بگذارید.
2. Settings ← Pages ← Source را روی **GitHub Actions** بگذارید.
3. با هر تغییر در `web/` سایت خودکار منتشر می‌شود. نشانی: `https://USERNAME.github.io/REPO/`
4. صفحهٔ حریم خصوصی: `https://USERNAME.github.io/REPO/privacy.html` (برای فرم مایکت و بازار).

## ۲) ساخت APK با گیت‌هاب (بدون نصب چیزی)
1. **کلید امضا** (یک بار، روی کامپیوتر خودتان؛ آن را گم نکنید، بدونش نمی‌توانید به‌روزرسانی بدهید):
   ```
   keytool -genkeypair -v -keystore release.jks -alias kafinet -keyalg RSA -keysize 2048 -validity 10000
   base64 -w0 release.jks > release.b64      # در مک: base64 -i release.jks
   ```
2. در گیت‌هاب: Settings ← Secrets and variables ← Actions، این چهار مورد را بسازید:
   `KEYSTORE_BASE64` (محتوای release.b64)، `KEYSTORE_PASSWORD`، `KEY_ALIAS` (مثلاً kafinet)، `KEY_PASSWORD`
3. Actions ← **Build Android APK** ← Run workflow (یا یک تگ مثل `v1.0.0` بزنید).
4. در پایان از بخش Artifacts فایل `kafinet-apk` را بگیرید:
   - `app-debug.apk`: برای آزمایش روی گوشی (ورود آزمایشی روشن)
   - `app-release.apk`: **همین را به فروشگاه‌ها بدهید** (امضاشده، ورود آزمایشی خاموش)
   اگر Secrets نگذاشته باشید فایل `app-release-unsigned.apk` ساخته می‌شود که قابل نصب نیست.

## ۳) ساخت با Android Studio (اختیاری)
پوشهٔ `android/` را باز کنید و Sync بزنید. برای اجرا Build ← Build APK. پوشهٔ `web` خودکار داخل برنامه می‌رود. نشانی‌ها و نام بسته در `android/app/build.gradle`:
- `applicationId`: `ir.kafinet.hoshmand` (قبل از اولین انتشار در صورت نیاز عوض کنید؛ بعد از انتشار قابل تغییر نیست)
- `versionCode` را برای هر به‌روزرسانی یکی زیاد کنید.

## ۴) انتشار در مایکت و کافه‌بازار
۱. در پنل توسعه‌دهندگان هر فروشگاه حساب بسازید (ممکن است احراز هویت بخواهند).
۲. برنامهٔ جدید بسازید و `app-release.apk` را بارگذاری کنید.
۳. متن‌ها را از `store/STORE-LISTING-FA.md` کپی کنید.
۴. آیکن: `store/icon-512.png`. اسکرین‌شات‌ها را خودتان از گوشی بگیرید (دست‌کم ۴ عدد).
۵. نشانی حریم خصوصی: صفحهٔ privacy.html روی GitHub Pages.
۶. ایمیل پشتیبانی: NimaHojaty4@gmail.com
۷. بازبینی را منتظر بمانید. اگر رد شد معمولاً دلیل را می‌نویسند (آرم سازمان‌ها، ادعای رسمی بودن، حریم خصوصی).
شرایط و فرم‌های فروشگاه‌ها ممکن است تغییر کرده باشد؛ آخرین نسخه را خودتان در پنل بخوانید.

## ۵) وصل کردن سرور هوش مصنوعی (کارِ خودت، ۱۰ دقیقه)
سرور آماده است: `functions/worker.js`. جستجو فقط روی فهرست سایت‌های رسمی داخل همان فایل (`OFFICIAL_DOMAINS`) انجام می‌شود، لینک غیررسمی از پاسخ حذف می‌شود و اگر عدد یا شرط در پاسخ باشد، جملهٔ «ممکن است بعضی از شرایط تغییر کرده باشد» به آخرش اضافه می‌شود.
۱. حساب رایگان کلودفلر (Cloudflare) بسازید. برای هوش مصنوعی کلید **Groq** و برای جستجو کلید **Tavily** (اختیاری، بدون آن جستجو انجام نمی‌شود) بگیرید.
۲. روی کامپیوتر (Node.js نصب باشد) در پوشهٔ پروژه:
```
npx wrangler login
npx wrangler secret put GROQ_API_KEY
npx wrangler secret put TAVILY_API_KEY
npx wrangler deploy
```
۳. نشانی‌ای که چاپ می‌شود (مثلاً `https://kafinet-hoshmand-api.NAME.workers.dev`) را در `web/config.js` جلوی `apiBase` بگذارید (بدون اسلش آخر).
۴. در `wrangler.toml` مقدار `ALLOWED_ORIGINS` را روی نشانی سایتت بگذار (مثلاً `https://USERNAME.github.io`) و دوباره `npx wrangler deploy`. برای APK، مبدأ برنامه `https://appassets.androidplatform.net` است و باید آن را هم، با کاما جدا، به `ALLOWED_ORIGINS` اضافه کنی.
۵. تغییرات را در گیت‌هاب بفرست تا سایت و APK جدید ساخته شوند.
کلیدها را هرگز داخل `web/` نگذار.
